トークンの作り方（初回のみ）
  1. GitHubにログイン → 右上のアイコン → Settings
  2. 左メニュー最下部の Developer settings → Personal access tokens → Fine-grained tokens
  3. Generate new token をクリック
  4. Repository access は「Only select repositories」を選び、sashiemichkazu.github.io を選択
  5. Permissions → Repository permissions → Contents を「Read and write」に設定
  6. 生成されたトークン（github_pat_...）をコピーして、上の欄に貼り付け「接続する」を押す
トークンはこのブラウザ（このパソコンのこのブラウザ）だけに保存され、GitHub以外のどこにも送信されません。他の人が使うパソコンでは「記憶を削除してログアウト」を押してから離れてください。
